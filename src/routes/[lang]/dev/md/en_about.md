# About Me

Hi, I'm **Ondrej Špánik** (iairu), a full-stack developer and DevOps engineer passionate about creating elegant solutions to complex problems.

## My Journey

My journey in technology started with curiosity about how things work under the hood. This curiosity led me to explore various aspects of software development, from frontend user interfaces to backend systems and infrastructure.

## What I Do

I specialize in:

- **Full-Stack Development**: Building web applications from concept to deployment
- **DevOps Practices**: Implementing CI/CD pipelines, containerization, and cloud infrastructure
- **System Administration**: Linux server management, networking, and security
- **Technical Writing**: Documenting solutions and sharing knowledge

## Philosophy

I believe in:

- **Clean Code**: Writing maintainable, well-documented code
- **Continuous Learning**: Technology evolves; we must evolve with it
- **Open Source**: Contributing to and learning from the community
- **Practical Solutions**: Solving real problems with appropriate tools
